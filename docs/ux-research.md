# UX / UE 调研与落地原则（2026-11-06，Asia/Shanghai）

参考：红果短剧移动端沉浸信息流、抖音/TikTok 桌面侧栏形态、同类 PC 短剧客户端、Spotify/Netflix 桌面壳；以及 Primer / 通用 empty-loading-error 模式。

## 成熟产品要点

| 来源 | 可借鉴 |
|---|---|
| 红果短剧 / 竖屏短剧 App | 顶栏极瘦（推荐+搜索）；底栏三键；首页沉浸竖滑；播放页信息压在画面底部；错误要可重试 |
| 抖音 PC / TikTok Desktop | **不用手机底栏**；左侧导航 + 主内容；键鼠快捷键 |
| Spotify Desktop | 侧栏优先「找内容」；主区信息密度可控；卡片圆角与轻微分隔；可折叠/分区 |
| Netflix | 空搜索不甩硬失败，尽量给替代路径；海报墙节奏统一 |
| 空态/错误通用原则 | 标题说明「为什么空」+ **一个**主操作；错误与「尚无内容」文案分开；避免技术堆栈 |

## DramaRed 约束（不可违背）

- **Android**：顶栏仅推荐+搜索；底栏首页/剧场/我的；首页竖滑→点进播放→切集；播放竖滑+预加载；剧场瀑布流；我的历史+收藏+设置（定时停）；后台听；不做下载。
- **Desktop**：侧栏+网格+9:16 预览旁侧控件；不照搬底栏。

## 本轮落地

1. 统一中文空态/错误卡片（Android `StatusPane`；Desktop 已有空态卡片并补历史空态）。
2. 海报卡片圆角/间距节奏（约 8–12pt）；设置页卡片分组提升可达性。
3. 保留 daemon Discover 空页降级与 502 误报修复。
