# Desktop UI 决策（对照 Android 与 X 上的同类应用）

调研时间：2026-11-05（Asia/Shanghai）。来源：X 公共搜索（`search_posts_all`）+ hongguo-open-player / 开心果 / 红果短剧电脑版等帖文截图说明。

## X 上同类应用怎么做

桌面短剧客户端几乎都不把「手机底栏 + 全屏竖滑」当唯一主界面：

- **hongguo-open-player**（跨平台桌面播放器）：顶部分类/搜索 + 海报目录；播放页是**竖屏按画幅适配的预览区 + 右侧分集/剧情**，底部进度、倍速、音量、全屏。快捷键对齐移动端手势（空格播放、上下切集、左右快进）。历史页标记看到第几集。
- **红果短剧电脑版 / hgplayer**：分类浏览或搜索即播；收藏、本机进度、选集、倍速、自动连播、老板键。强调免模拟器、上班摸鱼。
- **开心果（macOS）**：原生界面，推荐 / 排行榜 / 搜索 / 收藏 / 自动续播，安装包很小。
- **短剧库 Windows / TV 版**：电脑版是分类+搜索的桌面壳；电视版则针对大屏和遥控器，说明同一内容在不同设备上要换交互，而不是套手机皮肤。
- **better-douyin 等竖屏桌面工具**：左侧导航 + 主内容 + 沉浸播放，而不是底部 Tab。

和手机的差异要点：

| | 手机 | 桌面 |
|---|---|---|
| 导航 | 拇指底栏（首页/剧场/我的），顶栏很瘦（推荐+搜索） | 持久左侧或顶部导航，搜索常驻顶栏 |
| 首页 | 竖滑换剧的沉浸信息流 | 宽屏海报网格 / 分类目录 |
| 剧场 | 三列瀑布流 | 随窗口变宽的海报墙 |
| 播放 | 全屏竖屏，上下滑切集 | 9:16 预览框 + 旁侧选集/清晰度/倍速 |
| 输入 | 手势 | 鼠标 + 键盘（空格/方向键），可加老板键 |
| 后台 | 切到后台继续听 | 隐藏到托盘 / 窗口隐藏，音频继续 |

## Android 首版必须保留的能力

对照 `apps/android`（PR #20 产品壳）：

- **保留功能**：搜索、首页推荐、剧场、分集、在线播放（清晰度 / 倍速 / 自动连播）、历史续播、收藏、定时停播、后台听、预加载下一集。不做下载。
- **改形态**：不要底栏三键；首页不要竖滑 PageView 当唯一入口；播放不要全屏上下滑当唯一切集方式。「我的」里的历史/收藏/设置拆到侧栏，方便宽屏一眼看到。

## 本仓库桌面布局

- 左侧导航：首页推荐、剧场、搜索、正在播放、历史、收藏、设置。
- 顶栏常驻搜索；「隐藏继续听」对应后台听。
- 首页 / 剧场 / 搜索：宽屏海报网格。
- 播放页：左侧 9:16 手机比例预览框（封面 + 状态）+ 右侧选集芯片、清晰度、倍速、连播、定时停、收藏。画面仍由 libmpv 独立窗口输出（现有跨平台播放架构），预览框标明竖屏画幅，避免把竖屏内容硬拉成 16:9。
- 键盘：空格、↑↓ / PageUp·PageDown、←→、M、Ctrl+F、Ctrl+H、Esc。

## 关于「推荐失败 502」

**不是**本地 daemon 挂了，也**不是** UI 连错端口。

复现时 daemon `/health` 正常，Search 常仍 200；真正失败是 openhongguo `Discover` 解析推荐 tab 得到 0 条，返回 `ErrAnonymousLimited`（`anonymous response was empty`）。旧版 daemon 把**所有** ohg 错误一律写成 HTTP 502，UI 再用 `EnsureSuccessStatusCode` 甩出英文 `502 (Bad Gateway)`，造成「网关挂了」的误报。

处理：Discover 空页时 ResetDevice 再试 → Search/NewReleases 降级 → 短时缓存；错误分类不再把空页伪装成 502。
